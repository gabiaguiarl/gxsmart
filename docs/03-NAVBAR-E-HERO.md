# Navbar e hero

## Objetivo da etapa
Criar abertura cinematográfica navegável.

## Implementações realizadas
Header transparente com blur após 60px; menu mobile com Escape; CTA; título revelado em sequência; escultura Three.js.

## Arquivos modificados
src/main.js; src/scene.js; src/style.css

## Tecnologias utilizadas
Vite 6, JavaScript ES Modules, CSS, GSAP 3 e Three.js 0.180. Versões exatas em package-lock.json após instalação.

## Decisões técnicas
Three.js importado apenas em desktop sem redução de movimento. Torus knot metálico e acento roxo, luzes direcionais, sem imagens artificiais de projetos.

## Testes realizados
Lint sem erros; 2 testes passaram; build Vite aprovado. Inspeção visual desktop e mobile 390 × 844 realizada. Detalhes em docs/09-TESTES-E-CORRECOES.md.
